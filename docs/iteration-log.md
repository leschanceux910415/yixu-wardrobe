# 衣序开发迭代与失败分析

本记录按“观察问题—原因分析—工程改动—复验结果”整理迭代，覆盖模型联调、约束处理、澄清策略与天气推荐流程。

## 模型输出截断与联调

早期联调使用900 tokens输出预算，所用模型在默认thinking模式下出现JSON输出截断。

随后对所用服务禁用thinking，并将输出预算调整为1600 tokens；适配层识别 `finish_reason=length`，进入截断回退路径。thinking参数按服务兼容性发送。

调整后完成首轮真实混合策略37题调用，0降级、0执行错误；其中34题符合预标期待，3题进入诊断与澄清策略复盘。

## 约束与交互边界修复

| 问题 | 已实施的工程处理 | 可核对证据 |
|---|---|---|
| 冷天或正式场合被武断认为无解 | 显式条件与厚薄/正式度软偏好分开；外套各温度可选 | `tests/core.test.js`中的cold、outerwear、soft recent用例 |
| 只看Top K就判无解 | 在受限组合空间完整校验后再截取；超过枚举上限进入澄清 | core枚举逻辑与feasible/full space用例 |
| “不要白色鞋”被扩展为禁用所有白衣 | 作用域限定到匹配鞋类；泛指单品多命中时澄清 | core的color scoped、ambiguous garment用例 |
| 否定句误触发锁定，未知限制被已知颜色掩盖 | 分开识别正向动作与禁止；未支持的强条件保留待澄清 | core的negative wear、unknown prohibition用例 |
| 多轮修改丢失条件或重置后恢复旧锁定 | 保留未修改字段；重置清空上下文；模型更新需当前原文证据 | core multi-turn与service reset/evidence用例 |
| 模型输出衣橱外ID、选错候选或阶段状态不一致 | 校验ID与候选；失败明确回退；分别记录模型阶段 | service unknown/invalid selection/partial model用例 |
| 私有文件被静态路由访问 | 静态目录限定public，构建仅拷贝白名单文档与公开报告 | HTTP private resources测试、`scripts/prepare-public.js` |

工程回归使用受控输入与注入响应，覆盖条件作用域、多轮状态、候选校验与异常恢复；真实模型调用另按批次记录。

## 失败逐题复盘

| 用例 | 预标与输入 | 实际行为 | 原因判断与下一步 |
|---|---|---|---|
| D25 | 衣橱缺下装，应`conflict` | 模型生成“补充裤子或裙子”的clarification，系统返回`clarify` | 缺件事实被归入不支持条件，诊断类型不一致；修复后由确定性缺件检查定状态 |
| D27 | 空衣橱，应`conflict` | 模型要求先添加衣物，系统返回`clarify` | 修复后由确定性模块给出状态，模型建议独立展示 |
| D28 | 仅薄上装、裤、鞋；4°C正式需求仍有硬约束可行组合，应`ok`并说明软偏好距离 | 模型认为需先补正式厚衣，返回`clarify` | 把厚薄/正式度偏好升级为前置条件；修复后门控模型clarifications，保留合格结果与权衡 |

三题均因状态不符合预标而计入失败，首轮总结果为34/37。当前错误冲突字段统计 `conflict`，后续将单列不必要 `clarify`的次数与任务延迟，完善诊断指标。

## 澄清门控修复与三题定向复验

服务层按本轮连续原文与确定性解析结果门控新增澄清：明确的属性缺失或歧义进入确认流程，缺件事实交给可行性检查，气温与正式度保留为软偏好。尚待解决的历史澄清在多轮中继续保留。

工程验证新增缺下装、空衣橱、低温偏好、真实不支持条件和历史澄清等用例，完整自动化测试70/70通过。随后真实执行：

```text
node eval/run.js --version hybrid --case-ids D25,D27,D28 --out-dir eval/results/clarification-fix
```

3题全部符合预标，3题实际模型执行、0降级、0执行错误。D25和D27返回 `conflict`，D28返回 `ok`并完成候选重排。该批3题端到端中位数1063.38ms、P95为2133.57ms。[定向复验汇总](../eval/results/clarification-fix/hybrid-report.md)公开，原始JSON/CSV在本地归档。

首轮37题与修复后3题分别归档。下一批实验安排修复后完整37题复测、direct对照与独立任务测试；用户研究将开展访谈、盲评与连续试用。
